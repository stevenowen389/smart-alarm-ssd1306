You can create a custom command (let's call it alarm) that will instantly teleport you to that folder.

    Open your bash configuration file by typing: nano ~/.bashrc

    Scroll to the bottom of the file and add this line:
    alias alarm='cd /home/steven/smart_alarm/'

    Save and exit (in Nano, press Ctrl+O, Enter, then Ctrl+X).

    Reload your configuration by typing: source ~/.bashrc
