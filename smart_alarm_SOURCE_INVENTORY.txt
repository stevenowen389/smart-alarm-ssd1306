SMART ALARM SOURCE REFERENCE
============================

Purpose
-------
Top-level reference for the libraries, classes, functions, methods, and executable
scripts in this repository. Summaries are intentionally one sentence per entry.

Scope
-----
This inventory covers application source, playground programs, deployment scripts,
and bundled JavaScript libraries; binary assets such as .fzz and .bundle files are
not expanded because they do not expose source-level functions or imports here.

DEPENDENCIES AND LIBRARIES
==========================

Python dependencies from requirements.txt
------------------------------------------
adafruit-blinka       CircuitPython compatibility layer that exposes Raspberry Pi and
                       other hardware interfaces through common Python APIs.
adafruit-circuitpython-ssd1306 CircuitPython driver used to control SSD1306 OLED displays.
coloredlogs           Optional colored logging package declared for readable terminal logs.
colorschemes          APA102/LED color scheme helpers used to generate lighting colors.
gpiozero              High-level Raspberry Pi GPIO library used for amplifier control.
Pillow                Image, drawing, and font library used to compose OLED display buffers.
pygame                Multimedia library used for MP3 playback and audio mixer control.
pyttsx3               Offline text-to-speech library used to speak alarm messages.

Python standard-library modules used
-------------------------------------
base64                 Encodes and decodes request data in the web server.
cgi                    Parses multipart form submissions in the web server.
copy                   Copies XML element structures before comparison or mutation.
email                  Provides MIME-related parsing support where imported by scripts.
inspect                Inspects Python modules and platform objects in hardware diagnostics.
logging                Provides application and module logging.
os                     Provides files, paths, environment values, and operating-system commands.
os.path                Checks and joins filesystem paths.
random.randint         Chooses random wake-up music or effect values.
runpy                  Executes the smart_alarm package launcher.
subprocess             Runs operating-system commands in diagnostic and control scripts.
sys                    Reads command-line arguments and interpreter/platform state.
threading              Coordinates display activity and stop behavior across threads.
time                   Provides delays, timing, and clock values for hardware effects.
traceback              Prints diagnostic exception tracebacks.
urllib.request         Downloads MP3 content from a URL in the playground downloader.
wsgiref.simple_server  Supplies the standard-library WSGI development server.
webbrowser             Opens or integrates with a browser from the server entry point.
xml.dom                 Provides DOM XML parsing primitives.
xml.dom.minidom         Creates and reads XML documents in playground utilities.
xml.etree.cElementTree  Parses, compares, and writes the alarm XML configuration.

Hardware and platform libraries
--------------------------------
Adafruit_SSD1306       Legacy Python SSD1306 driver used as a fallback display backend.
adafruit_ssd1306       CircuitPython SSD1306 driver imported by the main display and demos.
board                  CircuitPython board pin definitions for I2C hardware.
busio                  CircuitPython bus interfaces used to construct the OLED I2C connection.
RPi.GPIO                Raspberry Pi GPIO library used by several playground hardware tests.
colorschemes            LED color generation helpers imported from the APA102_Pi ecosystem.
gpiozero.OutputDevice   GPIO output abstraction used to switch the audio amplifier.

External command-line tools invoked by code or setup scripts
-------------------------------------------------------------

============================
SHELL AND DEPLOYMENT SCRIPTS
============================

scripts/install_dependencies.sh
--------------------------------
Parameter $1                  Optional project root used when creating the virtual environment.
Top-level script              Installs Raspberry Pi OS packages, creates a Python virtual environment, and installs requirements.txt.

scripts/install_systemd_unit.sh
-------------------------------
Parameters $1 and $2          Project root and Linux user used to configure the service unit.
Top-level script              Creates, installs, enables, and starts the smart_alarm systemd service.

smart_alarm/autostart.sh
------------------------
Top-level script              Stops MPD, configures GPIO18 for PWM through gpio_alt, starts the alarm application, fixes permissions, and optionally starts Mopidy.

bundle_send_and_update.ps1
--------------------------
Parameter -InstallDependencies
                               Optionally requests dependency installation during remote deployment.
Top-level script              Creates a Git bundle, copies it to the Raspberry Pi with SCP, and optionally runs the remote update process.
